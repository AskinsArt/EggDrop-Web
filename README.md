## 🐣 About
**EGG DROP!** is a fast-paced 2D arcade-style Unity game where you play as a daring little bird trying to **drop eggs into moving nests** while avoiding **swooping hawks**.  

Every successful drop earns you points — but the hawks get faster and the nests trickier to reach! Stay airborne, stay sharp, and don’t get caught. 🐦  

---

## 🕹️ Controls

| Action | Key |
|:--------|:------|
| 🪽 **Flap / Fly Up** | `Spacebar` |
| 🥚 **Drop Egg** | `E` |
| 🔁 **Restart Game** | Click **Restart** |

🎯 **Goal:** Drop as many eggs into nests as possible without crashing or getting caught!
